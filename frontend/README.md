# Markdown Editor

A live markdown editor with real-time preview, built with **Next.js 16**, **React 19**, **marked**, and **Tailwind CSS 4**.

## Features

- Split-pane editor: write on the left, see live HTML preview on the right
- Formatting toolbar: bold, italic, headings, links, code blocks, lists, blockquotes, and more
- Download markdown as `.md` file
- Copy to clipboard
- Word and character count
- Dark-themed UI
- Fully client-side — no server needed

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
